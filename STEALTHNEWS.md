# StealthNews

StealthNews is a fork of [Stacker.news](https://github.com/stackernews/stacker.news) (MIT License).

The Lightning Network payment layer has been removed and replaced with non-custodial Monero via monero-lws.See [docs/specs/2026-07-25-stealthnews-design-spec.md](docs/specs/2026-07-25-stealthnews-design-spec.md) for the design specification.
